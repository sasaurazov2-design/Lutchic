# Исходный код сайта Lutchic

В этой папке собраны исходники сайта, настройки Vite и TypeScript, аватарка,
favicon, `robots.txt` и sitemap.

## Файлы сайта

- `src/App.tsx` — содержимое сайта и ссылки на соцсети.
- `src/index.css` — стили и адаптация под мобильные устройства.
- `src/` — остальные компоненты и исходный код.
- `public/avatar.jpg` — аватарка.
- `index.html` — заголовок, описание и настройки страницы.

Это исходники Replit-артефакта. В текущем Replit-проекте сайт запускается
из корня проекта командой:

```bash
pnpm --filter @workspace/lutchic-socials run dev
```

Зависимости управляются из корневого `pnpm-workspace.yaml`, поэтому для запуска
вне этого проекта потребуются настройки workspace и соответствующие пакеты.
